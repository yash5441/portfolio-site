# 🌐 Personal Portfolio Website

This is a **static portfolio website** built using basic web technologies — HTML, CSS, and JavaScript. It showcases personal projects, skills, and a brief introduction.

## 📁 Project Structure

portfolio/
├── index.html # Main HTML file
├── style.css # Styling for the portfolio
└── script.js # JavaScript for interactivity

## 🚀 Features

- Clean and responsive design
- Sectioned layout: Home, About, Projects, Contact
- Simple scroll animations and button interactivity
- Fully static (no frameworks or back-end)

## 🛠️ Technologies Used

- **HTML5** – Semantic structure and content
- **CSS3** – Custom styling and layout
- **JavaScript (Vanilla)** – Basic DOM manipulation and interactivity
